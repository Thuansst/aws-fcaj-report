# Report on “FCAJ Community Day”

## Purpose of the Event
* Understand foundational cloud concepts, system support realities, and cloud security practices through community knowledge sharing.
* Foster community bonding through an interactive technical quiz competition among FCAJ members.
* Gain practical insights into system operations, L1 support challenges, and cross-functional incident management in real-world engineering environments.
* Explore automated security assessment and penetration testing concepts using AWS Security Agent services.
* Understand the scope, preparation strategies, and career value of the AWS Certified Cloud Practitioner exam.

## Speakers
* **Nguyễn Huỳnh Sơn** – Engineer at Endava.
* **Thịnh Nguyễn** – Cloud & Security Specialist.
* **Guest Speaker** – AWS Certified Cloud Practitioner Guide.

---

## Key Highlights

### Main Content

#### FCAJ Internal Tech Competition
* Kickstarted the event with an engaging internal quiz competition designed to test members' knowledge of cloud, AI, and IT fundamentals.
* Created an interactive and collaborative environment for community members to exchange technical ideas and build connections.

#### System Engineering & L1 Support Realities (Nguyễn Huỳnh Sơn)
* Shared hands-on experience from working as an Engineer at Endava, focusing on operational support and system health.
* Emphasized a core operational reality: a healthy infrastructure layer (CPU, RAM, network uptime) does not automatically guarantee that the application or service on top is functioning properly for end-users.
* Highlighted the importance of a customer-centric mindset—engineers must prioritize resolving the user's actual problem rather than just closing tickets based on infrastructure metrics.
* Stressed the necessity of strong cross-team collaboration, bridging communication between L1 support, developers, and specialized infrastructure teams to tackle complex issues.

#### Automated System Security & AWS Security Agents (Thịnh Nguyễn)
* Introduced AWS Security Agent capabilities (e.g., AWS Inspector and AI-assisted security agent tools) designed for automated vulnerability management and system testing.
* Covered how security agents assist engineers in conducting security testing, identifying misconfigurations, and detecting software vulnerabilities continuously.
* Demonstrated how integrating automated security agents streamlines the penetration testing workflow and improves overall security posture.

#### Navigating the AWS Certified Cloud Practitioner Exam
* Provided a structured overview of the AWS Certified Cloud Practitioner exam, including foundational cloud concepts, billing, security, and core AWS services.
* Shared effective study strategies, key domain focus areas, and practical tips for beginners to validate their foundational cloud knowledge.
* Explained how earning this baseline certification helps structure early-stage cloud learning and opens doors for advanced specialization.

---

## Key Learnings

### Design & Operational Mindset
* Look beyond green infrastructure dashboards, true operational health requires evaluating the entire application stack and the end-user experience.
* Treat incident handling as a collaborative effort; proactive communication across different engineering tiers accelerates root-cause resolution.

### Technical & Security Architecture
* Automated security testing and agent-based vulnerability scanning are essential for maintaining continuous system resilience in cloud environments.
* Security should be embedded directly into operational workflows rather than addressed only during periodic manual audits.

### Career & Certification Strategy
* Building a solid foundation through certifications like AWS Certified Cloud Practitioner provides structured knowledge, conceptual clarity, and credibility.
* Interactive community events and gamified learning (like technical quizzes) are highly effective tools for reinforcing concepts and building professional networks.

---

## Application to Work

* **In infrastructure & operations:**
  * Adopt a holistic troubleshooting approach that evaluates both lower-level infrastructure metrics and upper-level application logic during operational incidents.
  * Actively break down communication silos by establishing clear escalation paths and collaborating closely with developers and higher-tier support teams.
* **In cloud security & testing:**
  * Leverage AWS security tools and security agents to automate routine vulnerability scans and proactively catch configuration risks early.
* **In professional development:**
  * Establish a structured preparation plan for foundational certifications (such as AWS Cloud Practitioner) to formalize cloud knowledge and advance career progression.

### Mục tiêu Tuần 8:

- Kết nối ứng dụng React Frontend với FastAPI Backend thông qua các REST API.
- Triển khai ứng dụng Full-stack lên máy chủ AWS EC2.

### Các công việc cần thực hiện trong tuần:

| Ngày | Công việc | Ngày bắt đầu | Ngày hoàn thành |
| :--- | :-------- | :----------- | :-------------- |
| 1 | **Tích hợp Frontend - Backend:** Kết nối các thành phần giao diện React (Xác thực/Auth, Danh sách thiết bị, Biểu đồ Telemetry) với các endpoint FastAPI. | 03/08/2026 | 04/08/2026 |
| 3 | **Chuẩn bị Triển khai EC2:** Kéo (pull) repository của backend về máy chủ AWS EC2, cấu hình các biến môi trường cho production (`.env`). | 05/08/2026 | 06/08/2026 |
| 5 | **Kiểm thử End-to-End & Xác minh:** Thực hiện kiểm thử tích hợp toàn bộ hệ thống giữa Trình duyệt, Backend và Cơ sở dữ liệu PostgreSQL. | 07/08/2026 | 08/08/2026 |

### Kết quả đạt được trong Tuần 8:

- Tích hợp thành công giao diện React Frontend với các REST API của FastAPI.
- Triển khai thành công ứng dụng thực tế trên máy chủ AWS EC2.

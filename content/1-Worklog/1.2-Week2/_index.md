### Week 2 Objectives:

- Master AWS IAM core concepts and security best practices.
- Perform hands-on IAM labs to manage users, groups, and policies.
- Configure IAM Roles and custom JSON policies enforcing the Principle of Least Privilege.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date |
| :-- | :--- | :--------- | :-------------- |
| 1 | **IAM Fundamentals & Deep Dive:** Study IAM architecture, Identity vs. Access management, Users, Groups, Roles, and Policies. | 22/06/2026 | 22/06/2026 |
| 2 | **User & Group Management Lab:** Create admin and developer IAM Users, assign them to User Groups, and enforce individual MFA. | 23/06/2026 | 23/06/2026 |
| 3 | **Custom Policy Authoring:** Write and test custom JSON policies using IAM Policy Simulator to restrict resource actions. | 24/06/2026 | 24/06/2026 |
| 4 | **IAM Roles & Service Authorization:** Configure IAM Roles for future EC2 instance usage without embedding hardcoded credentials. | 25/06/2026 | 25/06/2026 |
| 5 | **Security Auditing & Credentials Setup:** Generate AWS Access Keys for local CLI access and review Access Advisor/Credential Reports. | 26/06/2026 | 27/06/2026 |

### Week 2 Achievements:

- Mastered the core principles of identity and access governance on AWS.
- Successfully built custom JSON policies and verified permissions via Policy Simulator.
- Established secured IAM Users and Roles, eliminating reliance on the Root account for daily operations.

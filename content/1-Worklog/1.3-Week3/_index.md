### Week 3 Objectives:

- Understand core Amazon VPC networking components and cloud topology.
- Hands-on Lab: Design and build a Custom VPC from scratch.
- Configure subnets, routing, Internet Gateway, and network security rules.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date |
| :-- | :--- | :--------- | :-------------- |
| 1 | **VPC Theory & CIDR Planning:** Learn IPv4 CIDR block calculations, VPC architecture, Public vs. Private Subnets, and Availability Zones. | 29/06/2026 | 29/06/2026 |
| 2 | **Custom VPC Setup Lab:** Create a custom VPC (`10.0.0.0/16`) along with public and private subnets across multiple AZs. | 30/06/2026 | 30/06/2026 |
| 3 | **Routing & Internet Gateway:** Attach an Internet Gateway (IGW) and configure Route Tables for public subnet internet access. | 01/07/2026 | 01/07/2026 |
| 4 | **Network Security Rules:** Configure Security Groups (stateful) and Network ACLs (stateless) to control inbound/outbound traffic. | 02/07/2026 | 02/07/2026 |
| 5 | **VPC Verification & Testing:** Deploy temporary test resources inside the subnets to verify connectivity and network isolation. | 03/07/2026 | 04/07/2026 |

### Week 3 Achievements:

- Successfully built a custom isolated virtual network (VPC) from scratch.
- Configured proper internet routing via Internet Gateway and Route Tables.
- Implemented layered network defense using custom Security Groups and NACLs.

---

👉 **Outcome:** After Week 3, a secure Custom VPC networking infrastructure is fully operational, establishing the network environment to launch EC2 server instances in Week 4.
